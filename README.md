# PHP MVC E-Commerce

A vanilla PHP e-commerce application built with a custom MVC architecture — no frameworks.

## Features
- User authentication (register, login, logout)
- Product listing by category
- Shopping cart (session-based)
- Contact page

## Tech Stack
- PHP (vanilla)
- MySQL
- Custom MVC framework (routing, controllers, models)
- PDO for database access
- Tailwind CSS
- Vanilla JS (cart, header, index interactions)

## Getting Started

### Requirements
- PHP 8+
- MySQL
- Apache with mod_rewrite (or Nginx)
